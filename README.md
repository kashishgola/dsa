🚀 A complete collection of **Data Structures and Algorithms problems** ranging from **Easy to Hard**, designed to strengthen problem-solving skills and prepare for **coding interviews** and **competitive programming**.

## 📌 About the Repository

This repository contains:
- Well-structured solutions to DSA problems
- Problems categorized by **difficulty** (Easy, Medium, Hard)

The goal of this repository is to build strong fundamentals in DSA and maintain a structured record of solved problems.
